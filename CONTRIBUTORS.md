## Как попасть в список

1. Форкните репозиторий и внесите правки — код (`frontend/`, `server/`), деплой (`deploy/`, `docker-compose.yml`) или документацию.
2. Откройте pull request с коротким описанием изменений.
3. После принятия PR добавьте себя в таблицу выше отдельным коммитом (или попросите об этом в PR).

## Автоматический список GitHub

Помимо этого файла GitHub ведёт свой список контрибьюторов — по коммитам в основной ветке:

- **Вклад → Contributors** в репозитории;
- графа активности в профиле участника.

Учитываются и соавторы коммита — трейлер `Co-authored-by: Имя <email>` в сообщении коммита. Email должен быть привязан к аккаунту GitHub (подойдёт и адрес вида `ID+username@users.noreply.github.com`).
